---
title: "Install Peren"
description: "Install the released binary and verify that the CLI runs."
---

Install the released `peren` binary on Linux or macOS for x86-64 or ARM64:

```sh
curl -fsSL https://peren.dev/install | sh
peren --version
```

The installer places `peren` in `/usr/local/bin` by default. A successful `peren --version` proves only that the binary starts. It does not prove that storage, peer identity, or a Worker bundle are ready.
