---
title: "Metrics reference"
description: "Prometheus series exported by Peren on /metrics."
---

Peren exports these series from `/metrics` in Prometheus text format. Names and meanings match the HELP strings in the node metrics exporter. Do not invent additional series.

An operator may scrape `/metrics` with Prometheus.

## Process and listener

| Series | Type | Meaning |
| --- | --- | --- |
| `peren_build_info` | gauge | Peren build information. Label: `version`. |
| `peren_ready` | gauge | Whether this listener is ready to serve traffic. Label: `listener`. |
| `peren_listener_worker` | gauge | Whether this listener dispatches Worker traffic. Label: `listener`. |
| `peren_process_started_time_seconds` | gauge | Unix timestamp when this process started. |
| `peren_process_uptime_seconds` | gauge | Seconds since this process started. |
| `peren_configured_listeners` | gauge | Configured listener count for this node. |
| `peren_configured_services` | gauge | Configured service count for this node. |
| `peren_configured_queue_consumers` | gauge | Configured queue consumer count for this node. |

## Admission

| Series | Type | Meaning |
| --- | --- | --- |
| `peren_admission_capacity` | gauge | Concurrent top-level work admitted by this node. |
| `peren_admission_available` | gauge | Available top-level work capacity on this node. |
| `peren_admission_active` | gauge | Active top-level work currently running on this node. |
| `peren_admission_admitted_total` | counter | Top-level work admitted by this node. |
| `peren_admission_completed_total` | counter | Top-level work completed by this node. |
| `peren_admission_refused_total` | counter | Top-level work refused because the node was saturated. |

## HTTP

| Series | Type | Meaning |
| --- | --- | --- |
| `peren_http_requests_total` | counter | HTTP requests observed by this node. |
| `peren_http_errors_total` | counter | HTTP requests completed with a 5xx status or dispatch failure. |
| `peren_http_duration_ms_total` | counter | Total HTTP request wall time in milliseconds. |
| `peren_http_duration_ms` | histogram | HTTP request wall time in milliseconds. |

## WebSockets

| Series | Type | Meaning |
| --- | --- | --- |
| `peren_websocket_sessions_total` | counter | WebSocket upgrade sessions accepted by Workers. |
| `peren_websocket_sessions_registered` | gauge | WebSocket sessions tracked by the host registry. |

Duration histograms use fixed buckets at 1, 5, 10, 25, 50, 100, 250, and 1000 milliseconds, plus `+Inf`.
